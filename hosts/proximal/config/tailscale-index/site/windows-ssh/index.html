SSH into Windows

Quick setup using the built-in OpenSSH Server on Windows 10 (1809 or later) or Windows 11.

1. Enable the server

On the Windows machine, open PowerShell as Administrator and run:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Set-Service -Name sshd -StartupType Automatic
Start-Service sshd

This installs the server, enables startup at boot, and starts it now. Installation normally creates the firewall rule for TCP port 22.

2. Connect

From your other machine:

ssh username@windows-ip

Replace the placeholders with your Windows username and reachable IP address. Enter your Windows account password; the Windows Hello PIN is for local sign-in.

To find the account and network addresses, run on Windows:

whoami
ipconfig

For a local account shown as PCNAME\alice, use alice as the username.

If the connection fails

In administrator PowerShell, check the service and firewall rule:

Get-Service sshd
Get-NetFirewallRule -Name OpenSSH-Server-In-TCP

The service should show Running and the rule Enabled: True. See Microsoft's setup guide below for a missing firewall rule.

Reference: Microsoft OpenSSH setup guide. Updated September 15, 2026.
