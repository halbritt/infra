# archon

Read `machine.yaml`, `notes.md`, and the target subsystem README before changes.
This is the owner's interactive Omarchy desktop, usually with a live graphical
session on `tty1`. Do not reboot, log out, or restart Hyprland without owner
approval. Omarchy owns most of `~/.config` defaults; record any owner-directed
override here with its rollback. Credentials and Tailscale identity state stay
outside Git.
