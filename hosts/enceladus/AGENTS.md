# enceladus

Read `machine.yaml`, `notes.md`, and the target subsystem README before changes.
This is a shared family Windows desktop. The owner (`halbritt`) and a child
(`Saturn`) have separate accounts. Do not change the `Saturn` profile, reboot,
or sign anyone out without owner approval. Tailscale must stay in unattended
mode so that SSH from proximal works whoever logs in. Credentials and Tailscale
identity state stay outside Git.
